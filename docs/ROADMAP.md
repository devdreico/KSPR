# KSPR AI - Empresarial — alcance y primeras metas

## Entregado en v0.1

- Workspace web Phantom en escala de grises.
- Pegado y carga múltiple de archivos.
- CLI para directorios locales, ZIP y repositorios Git.
- Extracción de UI, eventos, rutas, operaciones de datos y dependencias.
- Iteraciones estructuradas y registro de contradicciones.
- Paquete Markdown + JSON.
- API FastAPI, jobs híbridos y persistencia Supabase opcional.
- Conexión real con Google Gemini, prueba de credenciales y listado de modelos habilitados.
- Shell de conversación estilo OpenCode: sesiones, paleta, comandos slash, Main Prompt, modelos manuales, pegar/arrastrar archivos, audio, copia y cancelación de jobs.

## Siguiente evolución

- Eventos de herramientas y una línea de tiempo de partes (el progreso y los deltas de texto ya usan SSE).
- Editor/árbol de archivos de contexto y permisos explícitos para cualquier herramienta futura.
- Sharing persistente de sesiones sobre Supabase y autenticación de workspace.
- AST especializados por lenguaje y adaptadores para repositorios monorepo.
- Grafo persistente de símbolos y relaciones con pgvector.
- Comparación entre versiones y análisis incremental.
- Evidencia visual mediante screenshots cuando el usuario proporcione capturas.
- Revisión humana por hallazgo y exportación de contratos OpenAPI.
